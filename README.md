## Learning Path

A practical learning path for this collection is:

1. Start with **Venus Web Recon** to establish web reconnaissance concepts.
2. Continue with **Venus: Enumerate the Orbit** and **Gobuster Grid Hunt** for enumeration practice.
3. Study **Venus User Enum** and **Hydra Username Hunt** for authentication and username-enumeration concepts.
4. Explore **Venus Web Cookie Hunt**, **Cookie Crumbs: Venus**, and **Cookie Vault Recovery** for cookie-focused security learning.
5. Continue with **Venus Cookie Forge** for additional cookie-security practice.
6. Study **Venus Access Chain** for access-control concepts.
7. Finish with **Venus Guest Session Hijack** and **Venus Admin Break-In** for session and authentication-focused CTF practice.

Adapt the sequence to your existing web-security and Linux knowledge.

## How to Use the Labs

1. Choose a lab from the index.
2. Open the corresponding Learn SecByte URL.
3. Read the objectives, scope, and prerequisites.
4. Work exclusively inside the authorized CTF or training environment.
5. Record the security concepts and observations from each exercise.
6. Understand the underlying security weakness rather than simply repeating commands.
7. Consider how the identified issue could be detected, prevented, or remediated.

For penetration testing learners, useful notes include the authentication boundary, enumeration method, exposed web resources, session behavior, security control involved, and potential defensive mitigation.
